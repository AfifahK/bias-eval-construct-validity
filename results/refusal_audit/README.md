# Refusal audit and corrected-set analyses

Hand audit of the refusal rule, the corrected operational refusal split, bootstrap CIs, and dictionary and LLM-judge scoring of the 154 audited refusals (158 are flagged by the regex rule; 4 declarative false positives are treated as scored responses). Figures and LaTeX tables are generated from the committed data. The as-submitted results files elsewhere in the repository are not modified.

- **Audited set.** Declarative: 63 refusals (4 of the 67 regex matches are not refusals), 297 scored. Operational: 91 refusals (20 responses were missed by the original regex because of curly apostrophes), 269 scored. As-submitted: 67/71 refusals, 293/289 scored.
- **Summaries.** `robustness_summary.md` (refusal ratios, flag ratios, family exclusion), `refusal_scoring_summary.md` (dictionary scores on refusals), `judge_refusal_summary.md` (LLM judges on refusals), `audit_precision.md`, `audit_sensitivity.md`.
- **Corrected-set statistics** (`corrected_stats/`). Flag rates, kappa with Holm correction, self-evaluation odds ratios and the interaction regression recomputed from stored labels on the 297 declarative and 269 operational scored sets (no new LLM-judge calls). Declarative output is the verbatim script output (`.md`); operational files are CSV. The 4 restored declarative responses take their Llama, Mistral and Gemma 1B labels from `hpc_refusal_judges/results_hpc/`.

## Reproduce

```bash
bash results/refusal_audit/reproduce.sh          # regenerate all numbers, tables (tables/*.tex) and figures (figures/)
bash results/refusal_audit/reproduce.sh --clean  # delete generated outputs first, then rebuild
git status --short results/refusal_audit         # empty = outputs match the committed ones
```

Needs python3 (3.9+) with the packages in `requirements.txt` and cached `mediabiasgroup/bias-lexicon` and `unitary/toxic-bert`. The HurtLex lexicon is not redistributed here. Obtain `hurtlex_EN.tsv` (English, version 1.2, under `lexica/EN/1.2/`) from the [HurtLex repository](https://github.com/valeriobasile/hurtlex) and point `HURTLEX_TSV` at it, e.g. `export HURTLEX_TSV=/path/to/hurtlex_EN.tsv`. If `HURTLEX_TSV` is unset, `reproduce.sh` skips the three steps that rescore text with HurtLex and the committed outputs are used; `score_refusals.py` exits with an error. LLM-judge calls (Ollama / SLURM, `hpc_refusal_judges/`) are not part of the script; their outputs in `hpc_refusal_judges/results_hpc/` are aggregated by `score_refusal_judges.py`. `corrected_stats/` is not regenerated by `reproduce.sh`.

Human audit of the refusal rule: code `refusal_audit_all67.csv` (`coder_label`: 1 refusal, 0 not, ? unclear), then run `python3 results/refusal_audit/audit_precision.py`.
