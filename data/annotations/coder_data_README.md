# Coder Annotation Data (not included)

Per-coder annotation files (`coder1/` through `coder6/`) and the merged qualitative analysis file are not released to protect participant privacy.

## What was here

- `coder{1-6}/annotation_sample*.csv` — individual human bias annotations on the declarative, naturalistic (MultiWOZ), and operational prompt samples
- `coder{2-6}/coder*_positionality.md` — coder positionality statements
- `qualitative_analysis_merged.csv` — merged annotations with per-coder labels and rationales

## What is available instead

- `annotation_sample_key.csv` — ground truth key showing which automated method flagged each item (no human labels)
- `annotation_sample_multiwoz_key.csv` — same for the MultiWOZ sample
- `ANNOTATION_GUIDE.md` — the codebook used by annotators
- Aggregate inter-rater agreement statistics in `results/tables/` and `results/agreement/`
